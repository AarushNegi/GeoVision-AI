# GeoVision AI

AI-powered image geolocation using deep learning, computer vision, OCR, and multimodal reasoning.

## Vision

GeoVision AI predicts the geographical location of an uploaded image by combining:

- Landmark Recognition
- OCR
- Object Detection
- Image Embeddings
- Geospatial Retrieval
- Explainable AI
